FAQ

Before you write

Can I use these projects in my work?
Yes. Projects released under the MIT license can be used, modified and redistributed, commercially too, as long as the license notice is kept. Check each repository’s LICENSE file.
Are they production-ready?
Each card shows its status. Those marked Alpha or MVP are under active development and their API may change. If you need one of them stable for your use case, we can work on it as a project.
Can I contribute or report bugs?
Of course! Open an issue or a pull request on the repository. Some projects have a CONTRIBUTING.md guide with the details.
My Fortran code is old and nobody understands it. Can you help?
That is exactly my specialty. First I analyze it (dependencies, complexity, risks) with tools like forti4d and fortriage, and tell you what to modernize first. Then we decide: wrap it for use from Python, refactor it or migrate it, checking that the numerical results do not change.
How do I hire you and how much does it cost?
It depends on the scope. After a first conversation I send a written proposal with a price. You can hire me on Fiverr, which protects payment for both sides, or directly by email.
Who owns the code of a contracted project?
You do. Once the project is finished and paid, the code belongs to the client. If it is confidential it stays private; if you want to release part of it as open source, I can help.
